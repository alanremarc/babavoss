# baba

The skill for making skills: the authoring app for software that agents operate, on the babavoss framework.
Requires Bun 1.4 or later.
Install with `bunx skills add alanremarc/babavoss`.
Ask the agent to use SKILL.md in the project's directory.
The agent opens it with `bun <the directory this file is in>/scripts/open.ts` and follows what it answers.
promptware shows an app's skill, references and open answer with their sizes; the playground tries tasks with the person.
Each app depends on the babavoss framework at the release this skill does, a tag of its GitHub repository; its door installs it before it first opens.
