Install babavoss in this project. Babavoss gives you surfaces: tools you read and act on through a command while I watch and act on the same thing on a page.

1. It needs Bun 1.4 or later. In the project's root directory run: `bunx github:alanremarc/babavoss init`
2. Check that `.baba/` was made, that `bun check` passes in it, and that `.claude/skills/baba` and `.agents/skills/baba` are there.
3. Start the shell: in `.baba/`, run `bun run baba start`. Its answer names the page's address.
4. How surfaces are made is in `.baba/node_modules/babavoss/skill/making-surfaces.md`; read it when I ask for one.
