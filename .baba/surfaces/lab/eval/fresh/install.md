Install babavoss in this project. Babavoss gives you surfaces: tools you read and act on through a command while I watch and act on the same thing on a page.

1. It needs Bun 1.4 or later. In the project's root directory run: `bunx github:alanremarc/babavoss init claude codex`
2. Check that `.baba/` was made, that `bun check` passes in it, and that `.claude/skills/baba/SKILL.md` and `.agents/skills/baba/SKILL.md` are there.
3. Start the shell: in `.baba/`, run `bun run baba start`. Its answer names the page's address.
4. Use the skill baba when I ask you to make a surface.
