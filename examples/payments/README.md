# Payments

Match a month's payments to invoices; the person decides unsure payments on the page.
Requires Bun 1.4 or later.
Put the app's directory among the harness's skills to install it.
Ask the agent to use SKILL.md in the project's directory.
The agent opens it with `bun <the directory this file is in>/scripts/open.ts` and follows what it answers.
Try the march preset with match-march, then learn-rule, in the playground.
